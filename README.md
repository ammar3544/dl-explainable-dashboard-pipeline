# Deep Learning & UI Explainable Pipeline: Model Prediction Dashboard

Repositori ini berisi studi kasus integrasi model *Deep Learning* dengan prinsip antarmuka dan visualisasi data interaktif, yang berfokus pada pengelompokan tingkat keyakinan model (*confidence level*) untuk meminimalkan beban kognitif pengguna akhir.

## Fitur Proyek
- **Neural Network Inference**: Memproses data masukan melalui arsitektur jaringan saraf tiruan terlatih.
- **Cognitive Load Reduction**: Mengkategorikan hasil probabilitas mentah menjadi status keyakinan yang mudah dipahami (*High/Moderate/Low Confidence*).
- **Dashboard-Ready Aggregation**: Menyiapkan ringkasan data makro untuk mendukung hirarki visualisasi interaktif.
